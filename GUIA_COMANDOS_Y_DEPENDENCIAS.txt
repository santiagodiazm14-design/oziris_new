================================================================================
           GUIA COMPLETA: COMANDOS, DEPENDENCIAS Y EJECUCION DE OZIRIS
================================================================================

Este documento contiene todos los requisitos, dependencias, variables de entorno 
y comandos necesarios para instalar, configurar y correr todo el proyecto OZIRIS
(Backend con NestJS + PostgreSQL / Prisma y Frontend con Next.js + React).

--------------------------------------------------------------------------------
1. REQUISITOS PREVIOS EN EL SISTEMA
--------------------------------------------------------------------------------
- Node.js: Version 18.x, 20.x o superior recomendada (incluye npm).
- PostgreSQL: Servidor de base de datos corriendo localmente (puerto 5432).
- Terminal o consola (PowerShell, CMD, Git Bash o terminal de VS Code).


--------------------------------------------------------------------------------
2. CONFIGURACION DE VARIABLES DE ENTORNO (.env)
--------------------------------------------------------------------------------

A) BACKEND: Archivo "backend/.env"
Crea o revisa el archivo en: backend/.env con los siguientes valores:

DATABASE_URL="postgresql://postgres:postgres@localhost:5432/oziris?schema=public"
JWT_SECRET="oziris_super_secret_jwt_key_2026"
PORT=4000
MAIL_USER="santiagodiazm14@gmail.com"
MAIL_PASS="xnax yobt bwba dcem"
FRONTEND_URL=http://localhost:3000

* Nota: Asegurate de que la contraseña y usuario de PostgreSQL coincidan con tu
  instalacion local de Postgres (por defecto postgres:postgres en el puerto 5432).


B) FRONTEND: Archivo "frontend/.env.local"
Crea o revisa el archivo en: frontend/.env.local con el siguiente valor:

NEXT_PUBLIC_API_URL=http://localhost:4000

- passport-jwt (^4.0.1)         : Estrategia JWT para Passport.
- reflect-metadata (^0.2.2)     : Reflexion de metadatos requerida por NestJS.
- rxjs (^7.8.1)                 : Programacion reactiva y observables.
- swagger-ui-express (^5.0.1)   : Interfaz visual interactiva de Swagger UI.

- prisma (^7.8.0)               : CLI de Prisma para migraciones y esquema.
- typescript (^5.7.3)           : Compilador de TypeScript.
- ts-node (^10.9.2)             : Ejecucion directa de archivos TypeScript (seed).

- prettier y eslint             : Formato y calidad de codigo.
- @types/*                      : Tipos estaticos de TypeScript para las librerias.

COMANDO PARA INSTALAR TODAS LAS DEPENDENCIAS DEL BACKEND:

--------------------------------------------------------------------------------
5. COMANDOS DE BASE DE DATOS (PRISMA)
--------------------------------------------------------------------------------
(Ejecutar desde la carpeta "backend"):

1. Crear o sincronizar las tablas en PostgreSQL segun el esquema:
   npx prisma db push

2. Generar el cliente de Prisma actualizado:
   npx prisma generate

3. Poblar la base de datos con datos de prueba iniciales (Seed):
   npm run prisma:seed   (o: npx ts-node prisma/seed.ts)

4. (Opcional) Abrir el visor visual interactivo de base de datos de Prisma:
   npx prisma studio
   -> Abrira una interfaz web en: http://localhost:5555


--------------------------------------------------------------------------------
6. COMANDOS PARA CORRER EL PROYECTO
--------------------------------------------------------------------------------

PASO 1: Iniciar el Backend (Terminal 1)
--------------------------------------
Comando:
  cd backend
  npm run start:dev

Salida esperada:
  🚀 OZIRIS API corriendo en:      http://localhost:4000
  📚 Documentación Swagger en:     http://localhost:4000/api


PASO 2: Iniciar el Frontend (Terminal 2)
---------------------------------------
Comando:
  cd frontend
  npm run dev

Salida esperada:
  - Local: http://localhost:3000


--------------------------------------------------------------------------------
7. COMANDOS PARA PRUEBAS (TESTS)
--------------------------------------------------------------------------------

Pruebas del Backend (Jest):
  cd backend
  npm test                  (Ejecuta las pruebas unitarias)
  npm run test:watch        (Ejecuta en modo observador en tiempo real)
  npm run test:cov          (Genera reporte de cobertura de pruebas)

Pruebas del Frontend (Vitest):
  cd frontend
  npm test                  (Ejecuta todas las pruebas unitarias de componentes)
  npm run test:watch        (Modo interactivo en tiempo real)
  npm run test:coverage     (Reporte de cobertura en frontend)

Pruebas de Carga y Rendimiento (k6):
  k6 run k6/test-register.js (Ejecuta prueba de carga registrando 150 usuarios en paralelo)
  k6 version                (Verifica la version instalada de k6)


--------------------------------------------------------------------------------
8. COMANDOS PARA CONSTRUCCION DE PRODUCCION (BUILD)
--------------------------------------------------------------------------------

Compilar Backend:
  cd backend
  npm run build
  npm run start:prod        (Inicia el backend compilado en modo produccion)

Compilar Frontend:
  cd frontend
  npm run build
  npm run start             (Inicia el frontend optimizado en modo produccion)
